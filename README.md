# ERP складу шпону

Локальний Flask-застосунок для обліку шпону за партіями. Підтримує каталог із фото та розмірами, партнерів, очікувані поставки, приймання скануванням, відвантаження, коригування, журнал руху та PDF замовлення.

## Запуск

Windows: двічі натисніть `start.bat`. Перший запуск створить `.venv` і встановить залежності з `requirements.txt`.

Linux/macOS:

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

Відкрийте http://127.0.0.1:5000 та створіть обліковий запис адміністратора. Дані зберігаються у `instance/warehouse.db`, фото — у `uploads/`. Робіть резервну копію обох папок.

Для сканера USB/Bluetooth поставте курсор у поле «Штрихкод / артикул» і скануйте. Камера телефону використовує браузерний BarcodeDetector (потрібен HTTPS або localhost і браузер з підтримкою API); ручне введення доступне завжди.

Локальний сервер за замовчуванням слухає тільки `127.0.0.1`. Для роботи кількох людей у мережі потрібне окреме захищене розгортання з HTTPS, резервним копіюванням та промисловою СУБД.
